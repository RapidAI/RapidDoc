# XLSX/XLS 共用表格投影

DOCX 性能验收通过后进入 XLSX。先移植原 `spreadsheet/projector.py`、`region_discovery.py`、`html.py` 的格式中立表格规则，供 XLSX 与后续 XLS 共用，未另写简化区域算法。

## 当前完成

- 使用稀疏有值坐标和合并格确定真实边界；有值判定与语义判定分开，保留空白字符串、未解析 DISPIMG、媒体与公式的原区别，不以工作表声明 dimension 扩大扫描。
- 四方向按最近内容洪水填充，保留“本区域内已有格立即停止该方向”规则；支持原显式 gap 和自动 0/1/2 候选。
- 移植空白率、内部空白线、连续分隔线、稀疏大表、singleton、行重叠的惩罚评分，保留原 0.15 近优范围与 1→0→2 偏好顺序。
- 按行缓存合并/隐藏格区间与锚点跨度；矩形物化保留空洞、合并跨度、源坐标、样式、富文本 HTML、图片和公式槽位。补齐真实样例中“新生成空格沿工作簿默认字体”的行为，不能把所有空格样式直接清空。
- 语义坐标严格子集过滤，不误删除语义集合相等的候选。合成选区保留非连续源行列、合并格可见跨度和源/显示坐标区别，供原图表源数据路径复用。
- HTML 保留首行 th、rowspan/colspan、空格、媒体 `<br>`、公式 `<eq>` 与原段落包装规则；singleton 仅在无合并、富文本、媒体或公式时投影为普通文字。

本阶段输入是原生 typed Sheet/Cell/Table，来源适配器之后提供单元格。冻结数据生成脚本中的 Python/openpyxl 仅用于差分验证；Rust 运行时没有 Python 回调或 JSON 往返。样式使用字符串映射，未构建完整 openpyxl 兼容对象树。

## 受影响验证

`export_spreadsheet_projection_reference.py` 覆盖 83 个 sheet（其中 20 个来自已有真实 XLSX），415 组显式/自动 gap 查询及 80 组非连续行列选择；比较边界、区域坐标集、评分、最终 gap、完整 ExcelTable IR、HTML 和输出块。构造样例覆盖稀疏空洞、合并、空白/布尔/零值、超声明样式尾部、媒体、公式、富文本与链接。

本阶段只跑电子表格投影、已共用的图表以及完整 Office 导出受影响测试，未重复运行全部元文件和 PDF/CUDA 测试。结果与 SHA256 见 `build/spreadsheet-projection-receipt.json`。

## 尚待

**还不能从公开 Python API 完整解析 XLSX**。下一步接工作簿/工作表原生读取与单元格物化，之后接图片、cell-image、图表、OMML/MTEF/OLE、包规范化重试、隐藏表和标题编排，再做完整输入到导出的验收。此阶段没有把当前用于图表的精简 XLSX reader 冒充完整转换器。

已有 `.venv` 中的 DOCX/PDF 包不因本内部模块而重新安装；DOCX 使用方式与效果保持不变。完整 XLSX 接入后再构建安装供直接测试。
