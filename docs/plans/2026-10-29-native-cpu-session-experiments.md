# 原生 CPU 会话实验

保持模型、FP32、预处理、候选和导出范围不变。实验包仅在 `build/dev-wheels`，当前 `.venv` 仍为已核对的 borrowed-layout-masks 包；不将单次有利结果自动发布。

## 已完成的整篇实验

按财报、03、密集长表顺序，单进程复用引擎，包含首次模型加载。每次均核对原参考 Markdown、content、已有 Rust middle 和图片像素。三篇所有输出核对通过。

| Rust 配置 | 财报秒 | 03 秒 | 密集长表秒 | 合计秒 |
| --- | ---: | ---: | ---: | ---: |
| 原调度 | 22.397 | 81.551 | 5.102 | 109.050 |
| 所有模型关闭自旋 | 14.726 | 86.450 | 6.284 | 107.460 |
| 动态负载块 4 | 18.039 | 90.573 | 5.178 | 113.791 |
| 仅版面和表格关闭自旋 | 18.422 | 91.622 | 6.235 | 116.280 |

关闭自旋减少 CPU 时间，但没有稳定整篇收益；不能作为默认优化。公式批量默认为 1，先前 batch2 默认已撤回，显式批量仍可实验。

固定公式输入的批形状特化也未稳定获益。1000us 限时自旋/backoff8 的前一组较快，最后一组默认又更快，未进入默认。

## 推理结束立即停止自旋

ORT [官方配置说明](https://github.com/microsoft/onnxruntime/blob/v1.26.0/include/onnxruntime/core/session/onnxruntime_session_options_config_keys.h)中的 `session.force_spinning_stop` 允许在 Run 返回时结束自旋，区别于整个推理过程禁止自旋。新增可选模型 engine_cfg 字段 `cpu_force_spinning_stop`，默认 None。该字段进入原生和 Python 会话缓存身份，避免不同策略误共享同一会话。这里只改变线程调度，不修改模型运算或精度。

Python 侧探路三篇 18.351 / 84.947 / 5.183 秒；随后默认对照 30.99 / 120.09 / 6.18 秒。均输出相同，但当前存在明显运行波动，顺序单次结果不足以认定收益。

随后使用同一个新原生 release 包，按原策略 A → 新策略 A → 新策略 B → 原策略 B 顺序、每组独立进程，运行相同三篇：

| 策略 | 财报秒 | 03 秒 | 密集长表秒 | 合计秒 |
| --- | ---: | ---: | ---: | ---: |
| 原 A | 21.647 | 83.135 | 5.222 | 110.004 |
| 新 A | 13.903 | 67.651 | 5.334 | 86.889 |
| 新 B | 16.897 | 71.652 | 3.201 | 91.750 |
| 原 B | 12.104 | 70.218 | 3.138 | 85.460 |

最后原策略也降到 85.460 秒，快于两次新策略，不能把首轮 21% 的下降认定为稳定调度收益。原两组合计均值 97.732 秒、新两组 89.319 秒，均值差 8.6% 仍受原 A 的慢值影响，**不作为默认启用或安装依据，不宣称比 Python 快很多**。进程 CPU 时间下降更一致，但用户目标是墙钟解析速度，不能替换指标。峰值工作集最终约 3.36–3.37 GiB，内存未见实质收益。

四组共 12 次整篇、80 页，Markdown/content/原有 Rust middle/图片像素均与参考一致。原生缓存隔离测试 1 项、SDK CPU 策略（含真实公式）、named 张量、5 组 OCR/CTC 测试通过；未跑全量或 CUDA。初次 SDK 测试命令误传了重复目录，修正为脚本名后通过，保留首次错误日志。当前安装 wheel SHA256 仍为 `15f16901fcfbeedae16908aeecb525dfc32b22fafedb7f60acfdc7e0e172ef17`，本轮未安装实验包。

排序批量 4 的 Python 探路在 03 上完整输出一致，整篇 100.876 秒，单次不足以证明加速，未移入生产。03 和 demo1 的全部 130 次公式输入中只有 129 个不同 FP32 张量，未加收益很小的输入缓存。

原始证据保留在 `build/native-policy-*-20261029`、`build/python-spin-stop-a-20261029` 和 `build/python-default-current-a-20261029`。不得覆盖已有参考文件或把 Python 探路结果称为 Rust 加速。

## 比较工具修正

Python 对照显式使用 SHA256 已验证的迁移公式模型，避免原本地模型不完整时下载掺入耗时。诊断下载已停止，本地公式模型用同 SHA 的完整副本恢复；冻结的 build/migration 证据未修改。新增公式输入哈希诊断和仅诊断用的排序批处理，均不改变生产 Python 模块。
