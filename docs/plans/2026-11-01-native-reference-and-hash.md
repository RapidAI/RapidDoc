# 原生 PDF 参考行、几何/标题整理和按需资产哈希

接续 [页面所有权和 RGB 渲染](2026-11-01-native-borrowed-context-and-rgb.md)，采样的是其最终安装包，不用更早版本的热点比例指导本轮改动。

## 定位与实现

- 新版主线程栈采样中，JSON 子树 clone 约占 29.0%，Value serializer 约占 25.1%；两者有重叠，不相加，也不是 CPU 时间百分比。原始栈和汇总：`build/borrowed-r2-stack-20261101.tsv`、`build/borrowed-r2-stack-summary-20261101.json`。优化链接器会合并实现，不能把每个叶节点的符号名称直接视为精确业务函数。
- 表格候选此前为了替换 drawing_lines，复制整份 analysis。现在只临时替换这个字段，同步检测结束后恢复，错误返回前也恢复；候选、顺序、阈值、仲裁不变。
- 文字角色与脚注在内部接收只读参考行，不再把整页行树复制到两个 options 中；source 的字段更新在原数组进行。角色算法自身必要的别名副本保留，避免改变对象身份规则。公开 JSON 适配入口及原校验仍在。
- 几何重拆请求移交修复后的行；输出数组、样式/链接和拆分成员移交所有权；更新来源行时借用结果映射，保持重复 source_index 的原覆盖规则。
- 最终标题整理复用同一个私有请求，移交每一步的结果数组，避免每次都复制上一份行树和中间 checkpoint。所有标题/正文/参考文献处理步骤仍执行。
- 组装前会解码并验证页面 PNG，但整页 MD5 只用于裁图/表内填图的文件名。此前所有页都算 MD5；现在首个实际资产需要命名时才计算，同页后续资产复用结果。没有跳过 PNG 校验，不按文件名或特定文档绕过规则。

仍保留 `arbitrary_precision`、`float_roundtrip`，也保留为兼容原 FP32 十进制提升行为而存在的 `pipeline::wire` 边界，未为了少一次转换取消精度契约。

## 验证

- 新增 235 组固定 Python 文字角色/脚注场景的显式参考行借用对照，在有限预算和生产作用域各跑一轮，共 470 组。核对输出/错误与 Work 计数；271 组原固定参考也通过。
- 固定最终页面参考通过，覆盖公开、所有权移交、无重复几何字符快照三条路径。
- 最终安装版 16、65、129 页及密集长表格的完整快照与上版严格一致。默认模型扫描、论文、印章共 6 组公开选页/单页窗口对照通过。
- 按需 MD5 的 36 组安装对照覆盖 L/LA/RGB/RGBA、无资产、裁图、印章、表内填图重复 UUID、混合图、原图提取与坏 PNG。页面结构、资产名、写入顺序、像素与 PNG 字节不变，坏 PNG 仍报错。脚本：`scripts/migration/accept_asset_hash_cache.py`。
- 安装资源策略 5 项通过。未跑无关 Office、全 workspace、全 PDF 或 CUDA，也未重新量化峰值内存。

第一批参考/几何/标题改动的独立顺序计时（还未包含 MD5）：上版首次/热调用 18.626/18.382 秒，该批 16.625/17.101 秒；原生分析 13.506/13.233→11.477/11.925 秒，组装仍约 2.74 秒。原始数据：`build/native-reference-comparison-20261101/report.json`。
