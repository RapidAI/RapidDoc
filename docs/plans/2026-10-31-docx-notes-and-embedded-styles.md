# DOCX 附注、嵌入样式映射与表格预解析

本阶段把原 Mammoth 表格转换使用的脚注、尾注、批注和 `mammoth/style-map` 接入 Rust DOCX 正文。继续移植原流程，没有更换解析算法、模型或 PDF 接口。

## 行为

- `style_map.rs` 移植原 token、匹配及 HTML path 语法：段落/字符/表格 style ID、名称匹配和前缀、编号层级、有序/无序列表、直接 run 属性、highlight、换行和批注引用。支持路径嵌套、候选标签、属性/class、fresh、separator、转义、空映射及 ignore；逐行忽略无效规则并记录与原文一致的警告。嵌入映射优先于原默认映射。
- `table_resources.rs` 按原流程先转换正文顶层表格，再解析引用的脚注/尾注和批注内容，最后按已有 XML/HTML 签名顺序对齐候选表格，并注入公式、修正 colspan、校验链接。保留预解析筛选掉外层包装的行为，以及映射后匹配不到候选时的完整上下文回退。
- 脚注和尾注共用引用顺序；重复 ID 仍逐次编号，批注使用独立计数和作者缩写。separator/continuationSeparator 不作为普通附注。缺失附注、未引用但 XML 无效的附注等会按原流程使预解析退回逐表转换；逐表转换使用独立引用状态，不延续预解析失败时的编号。
- 保留原输出范围：正文表格含引用标记，附注/批注内容参与原转换和资源处理；本阶段没有另外设计文末附注导出格式。
- 附注与正文使用各自的关系表，转换结束或异常后恢复正文关系；图片字节仍复用共享 ZIP/Arc 部件。引用序列在 reader 间转移，关系表和批注缩写使用 Arc，不按每次附注重新复制完整引用历史。
- 媒体载体使用延迟资源节点，待 enclosing HTML 路径确定后处理；ignore 分支不会触发本应隐藏图片的解码或外部资源读取。保留 VML extra 节点的原处理顺序。
- 原 `DocxConverter` 对表格转换错误的处理是告警并继续正文。Rust 正文边界已对齐：记录具体表格与错误，继续后续块；没有把内部独立表格函数的错误取消掉。文档容器本身的错误仍由原容器加载层报告。

## 验证

`export_docx_resources_reference.py` 从未修改的本地 Python 行为生成参考：

- **56 组样式映射 × 20 组匹配查询，共 1,120 组**：逐项比较警告、匹配和最终折叠 HTML，覆盖语法、大小写、转义、属性覆盖和无效规则。
- **81 份完整 DOCX**：嵌入映射、优先级/列表/分隔符、混合与重复附注、缺失部件、separator、附注内引用/表格、未引用坏附注、批注、隐藏外部图片，以及附注与正文同 rId 不同图片的关系隔离。比较完整原 `DocxConverter.convert()` pages；表格图片仍比较原载荷 HTML。
- 此前 **272 份完整正文参考**、图表、公式、位图/矢量和其他 Office 路径的阶段 **59 项测试通过**。随后补充附注表格容器边界，只复查受影响的正文/资源 **3 项测试，均通过**；最新合计 353 份文档参考（352 成功、1 预期损坏）、362 逻辑页。结果与 SHA256 见 `build/office-docx-resources-receipt.json`，日志为 `build/office-docx-resources-tests.log`。

Python 仅用于生成原行为参考，Rust 运行期不调用 Mammoth 或 Python。沿用已有 Mammoth/DocVortex 许可声明；未引入新的运行库。

## 交付边界

DOCX 的统一结果导出、公开 Office/Python API 与安装包接入仍待完成；少见图片格式、更复杂客户文档及跨平台仍需继续验收。本轮未更新 `.venv` 的 `rapid_doc_rust`，未跑全量 PDF/CUDA，也没有性能或峰值内存基准。
