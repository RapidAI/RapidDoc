# M 模型缓存与形状处理后续实验

## 结论

本轮未测出可确认的额外提速，**继续保留上一轮注意力融合候选，不替换默认模型或安装包**。以下仅为独立实验，不宣称节点更少就一定更快，也不将不同时间段的耗时用于累计倍率。

## 缓存更新融合

在 6 组自注意力中，将原来的历史 K/V、当前投影结果交给 `MultiHeadAttention`，由该算子直接产生 present K/V，替代外部 Concat 和部分 reshape/transpose。原有注意力掩码、已缩放 Q、权重、输出词表与终止规则保持不变。

这不是缓存原地更新或零拷贝：算子内部仍需要处理历史缓存。本次没有使用预分配共享缓存、自定义内核或修改最大序列长度。

新候选通过 ONNX checker 和全部 74 个冻结公式的原始 token 校验。自动线程单轮 29.962 秒；同一实验序列之后的上一轮融合候选对照为 29.388 秒，未显示新增收益。

为检查融合结构的线程需求，另外测试了同一缓存候选：

| 配置 | 74 个公式推理耗时 | 原始 token |
| --- | ---: | --- |
| 自动线程 | 29.962 秒 | 74/74 一致 |
| 1 线程 | 115.843 秒 | 74/74 一致 |
| 4 线程 | 50.673 秒 | 74/74 一致 |

这些是诊断性单轮测量，未用于选定新的默认线程数。单线程和 4 线程均明显慢于当前自动线程，未进一步扩大试参。所有实验采用独立进程，没有调整系统电源、CPU 亲和性、其他应用或默认配置。

生成过程曾因图重建后 protobuf 子图引用失效造成拓扑检查失败，已修正为清理后重新获取子图再排序；只有通过 checker 的 v2 候选参与推理。失败目录不作为可用模型。

## 等价形状读回简化

只跟踪可以证明保持形状的运算，例如 Cast、单输出 LayerNorm、标量广播；识别 `Reshape(y, Shape(x))` 中 y 与 x 同形状的情况，以及重复的完整 Shape 查询。不固定 batch、公式长度或图片内容，不根据文档加条件。

共移除或复用 17 处操作，独立候选通过 ONNX checker、74/74 原始 token 校验。单轮 30.954 秒，相对紧邻的上一轮融合候选 29.388 秒未显示收益，因此未接入。

这不是完整 ABBA 性能结论，无法证明每次都更慢；但已有证据不足以采用新候选。为避免对无明确收益的变化继续投入大量回归，本轮没有再跑全量或 PDF 对照。
