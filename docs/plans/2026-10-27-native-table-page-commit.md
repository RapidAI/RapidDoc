# 正式整页准备：表格检测与提交贯通

接通旧 `_prepare_page_source` 中表格部分的连续阶段：保护已分类来源行、以分析视图计算强图形及数值表证据、避免数值表被强图形抢占、去掉已确认页眉分隔线、完整表格检测、回到原始行物化与认领、数值网格标记、剩余行及页末续表轨道。

阶段入口接收真实PageSource及此前已确认的排除框/已提交块/认领行/页眉分隔线；不接收预选表格或恢复结果。原始行和分析行之间保留共享对象副作用的对应关系，按源行数组位置传递副作用；来源号须唯一，重复号继续按既有提交接口拒绝。检测与提交使用同一Work；提交失败不发布部分结果。

这不是完整 `_prepare_page_source`：目录/代码/Form选择、图形与图像块提交、几何修复、公式及后续文本分类仍需正式接线。不能借表格阶段贯通开启默认PDF完成标志。验证以旧原函数组合执行，不替换恢复器或注入候选；阶段末一次wheel和受影响回归，无全量/CUDA。

## 实现与验证

- PageSource分析视图只排除预分类/先前认领行，候选物化返回原始行，允许表体内误标边缘文本按旧逻辑重新认领。
- 强图形标题副作用按原数组位置传回源；数值表反证在图形避让前过滤；已确认页眉分隔线只影响候选绘图线，恢复与轨道仍使用完整源线。
- 注释有序行框在候选/提交接口之间显式转换，不接受上游表格结论。提交、认领、数值旗标和末表轨道从真实结果计算。
- 表注准备此前对反向绘图线框调用严格rect，导致旧Python可接受输入被提前拒绝；仅绘图线改读原方向有限坐标。反向校准框及重复来源号等既有拒绝合同不改。
- 144个有效旧连续组合参考，另2个重复来源号合同拒绝。原始参考均保留，不能把这2个拒绝称旧Python等价。
- 59页实时PDF集成：41页输出表格/6页输出末表轨道；source和字形框/原点全部实时重建。既有冻结源的图片/Form框保持其证据，不能据此宣称完整Form读取或整页语义已实现。
- 31受影响Rust单元测试、59页集成通过。115模块清单、固定36＋3＋1上游哈希维持；runner登记133组安装套件及独立PDF渲染，本轮不全跑，无CUDA。
