# DOCX 正文、目录、分节与页眉页脚

本阶段将原先独立的段落上下文、编号、公式及表格组件接成实际正文流程，并补齐目录/锚点、文本框及页眉页脚。它已能对本阶段覆盖的文档输出与原 `DocxConverter.pages` 一致的结果，**还不是完整 DOCX 公开入口**。

## 已接通

- `docx/body.rs`：正文按源顺序编排标题、普通文本、题注、行内/独立公式、表格、列表和目录。表格调用此前已移植的 Mammoth 结构、公式注入及图片资源链路。
- 列表沿原 numId/ilevel 状态机：增加缩进、减少缩进找父级、异常层级恢复、表格/普通正文边界、跨块编号连续和父级前进后子级重启。穿插正文且具有多个层级的列表保留原“章节标题列表”识别。编号仍用任意精度整数，JSON 输出不经过 f64；80 位起始编号和递增结果已严格检查数字文本。
- 目录支持普通 TOC 段落、SDT、显式/复杂域链接目标、连续目录基准层级、多级数字深度修正、图表清单扁平化、bookmark alias 选择和输出锚点。保留原版缺失目录父层级时的处理，没有另造层级算法。
- 分节沿原逻辑生成逻辑页；纯布局 continuous/零页边距分节不额外分页。这里的页是原生 Word 语义逻辑页，非重新排版后的物理页。
- 文本框按原 XPath 选择、容器首次出现顺序、段落兄弟位置排序，以及 `(文本,位置)` 去重；包含 VML、现代 DrawingML 与原替代载体规则。文本框内容仍在外部段落前处理，保留原顺序。
- 页眉页脚按 section 继承相应部件；默认/奇偶/首页选择、段落之间插空格、每节按可见文本去重、纯数字过滤及页数不足时的诊断均沿原实现。支持 part 局部超链接和公式关系，共享累计二进制公式/图片预算。
- `docx/spans.rs`：具名 Rust Span，样式合并、安全链接、Unicode 字符切片、首尾裁剪和公式位置注入。保留原“原始文本及格式文本均能重构才插入公式”的检查。修复验证发现的 HyperlinkSpan 内部默认 `styles: []` 字段与顶层文字字段省略之间的差别。
- 新增的 Python `str.isdigit` 非 decimal 范围由既有 Unicode 16.0.0 生成器冻结，供页眉页脚纯数字过滤；不以 Rust `is_numeric` 近似替代。生成器 `--check` 通过。
- `Body` 同时携带包级修复报告、矢量渲染诊断及图片占位回退报告。XML/资源仍由 Package/Arc 共享；运行阶段无 Python 回调或中间 JSON 指令树。serde 只在结果边界序列化，RawValue 仅用于精确输出大整数。

## 验证

`scripts/migration/export_docx_body_reference.py` 调用当前原 Python 的完整 `convert()`，不是单独调用新 helper 生成期望结果：

- **97 份 DOCX，96 份成功、1 份保留输入损坏错误，104 个逻辑页**。比较整个 pages，包括块顺序、嵌套内容、样式/链接、编号、锚点、公式、表格、页眉页脚。
- 包含 30 份固定随机种子的混合列表/标题/表格文档、多种目录跳级、列表/目录交界、字体样式、中文/非 BMP 字符、分节、奇偶/首页继承、纯数字页眉、文本框重复与替代载体。
- 直接读取已有 `demo/docx/equations.docx`、`section.docx`、`textbox.docx`，原/新完整输出一致。`空白.docx` 实际非有效 ZIP，保留失败；另有 4 份二进制/图片 MTEF 包完整输出一致。构造语料和已有示例不能替代所有客户文档验收。
- **450 组富文本参考**：含样式和安全/非法链接的分组、相邻合并、换行、首尾空白、Unicode 切片、公式插入及原回退检查。
- 阶段 `cargo test --locked -p rapiddoc-office` **54 组测试通过**；没有全量 PDF/CUDA、生产 wheel 重建或性能/峰值内存基准。`.venv` 中 rapid_doc_rust 未替换。

## 尚待完成

正文图片序列化/普通位图转码、图表、表格附注/嵌入样式映射等剩余资源处理，以及统一 Office 结果导出和 Python 原 API 接入仍需继续。当前遇到未接通的正文图片或图表路径明确返回 Unsupported，避免输出被误认成完整转换；这只是迁移阶段的可见缺口，不是对最终兼容能力的新限制。

Windows/BASIC 字体环境、跨平台/复杂排版、少见图片编码和真实语料覆盖的风险继续沿前阶段记录保留。本轮没有修改原 Python 的解析算法，也不承诺尚未实测的性能收益。
