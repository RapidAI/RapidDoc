# 原生处理重复开销优化

要求：不降低精度，不按文件名、文档特征或特定内容增加分支，不更换算法、模型、阈值、识别批次或 padding。

## 修改

- 正式 Rust 管线将公式裁图作为借用 RGB 像素传给推理，省掉中间 PNG 编码和三次解码；公开 PNG 推理入口只解码一次并复用。原裁框、扩边、裁图顺序、source ID 保持一致。扩边为零时保留原多边形遮罩路径。公式像素在当前页推理后释放，不随跨页窗口保留。
- 表格单元格样式渲染借用整页字符、tight bbox 和 origin 映射，避免每个单元格重新构造、深拷贝整页 JSON。公开接口的校验、工作预算、异常行为不变。
- 共用 Pillow 缩放按输出行访问，三个通道共享像素读取；保留系数、每通道整数 tap 累加顺序、舍入、钳位及两遍缩放次序。
- Rust 阶段日志增加 formula_validation、formula_preprocessing、formula_inference、formula_decoding，Python 仍只负责显示。

## 验证

- 60 组原区域规划分别检查扩边 0/2：任务计划、source ID、未替换 PNG、公式像素及内存/PNG 路径的 FP32 张量完全相同。
- 88 组原公式预处理 RGB 精确，原 Python 张量最大绝对误差 2.38418579e-7（原兼容容差 1e-6）；673 组修复、1352 组解码、4 组真实 M 模型 CPU 批次和跨页回填通过。
- 526 组表格 HTML、724 组恢复、32 组真实 PDF 表格链通过；85 页图片信息、57 图片及共用缩放证据通过。
- API 默认/原生变体、119 模块来源审计通过。只构建 release、只跑受影响测试，未跑全量或 CUDA；旧冻结参考未改动。
- 四份用户 PDF 共 38 页：Markdown、middle JSON、content list 与原 Python 全部相同，64 PNG 资产与已验证旧 Rust 包逐字节相同。

## 性能证据与限制

初次构建后与较早计时相比，新旧包均明显变慢，连未修改的版面/ORT 阶段也变化较大。因此不将不同时刻整篇计时差当作此次优化的收益。

改用两个独立常驻进程、预加载相同输入，新旧包交替执行，每轮互换先后顺序，首轮预热不计，保留 7 组结果；输出哈希完全相同：

| 组件输入 | 旧包中位耗时 | 新包中位耗时 | 耗时下降 |
| --- | ---: | ---: | ---: |
| 88 组公式预处理 | 0.374019 s | 0.308931 s | 17.4% |
| 526 组表格渲染 | 1.644949 s | 1.425428 s | 13.3% |

这些是组件结果，包含现有接口调用开销，不代表任意文档、平台、整篇或峰值内存的收益。内存公式通路省下的 PNG 往返不在单独预处理组件计时中。

本次新包整篇耗时为 36.929 / 84.276 / 10.266 / 95.202 s；随后旧包同一顺序为 29.616 / 56.557 / 7.193 / 132.991 s。两次波动方向不一致，不能据此宣称整篇普遍更快或更慢。保留全部原始记录，后续正式比较需约束机器负载和运行条件。

细分记录显示：本轮 demo1 的公式预处理 0.761 s、推理 54.096 s；03 为预处理 0.728 s、推理 63.192 s。公式主要时间仍在 ONNX Runtime 推理，不能把其余数十秒归因于 PNG 转换。原生阶段编排及推理执行仍可继续分析，未为了速度调整模型或缩小图像。

证据：`build/overhead-paired-workers.json`、`build/overhead-four-summary.json`、`build/overhead-control-four-summary.json`、`build/overhead-*-test.txt`；新整篇输出位于 `build/overhead-four/`。构建日志 `build/overhead-native-build.txt`，本轮生产 release 构建 8 分 57 秒，专项测试目标另行编译；二者均已结束后才运行整篇计时。

新包已安装到项目现有 `.venv`。安装后的原生二进制、Python 适配器和兼容审计与测试 wheel 逐字节一致，wheel 全部 RECORD 哈希/长度校验通过，`pip check` 正常；无需为相同二进制重复整篇回归。旧安装 wheel 保存在 `build/pre-overhead-wheels/`。安装日志：`build/overhead-install.txt`、`build/overhead-pip-check.txt`。其他交付任务（PDFium 共存、印章、正式质量/性能/峰值内存对比）不在本次通用开销优化的完成声明内。
