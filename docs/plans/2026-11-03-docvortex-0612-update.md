# DocVortex 0.6.12 选择性同步

目标：保留 RapidDoc 的本地版面、网格、字距、模型和回退策略，迁入 0.6.8 后与七种支持格式相关的修复。历史 0.6.8 清单保留，新的精确来源和当前 Python 文件哈希见 `rapid_doc/_vendor/docvortex_core/UPSTREAM_0612.json`。本项目仍是选择性分支，不能标成完整上游 0.6.12。

## 本次实现

- 0.6.9 `a4f6e7a`：重复全宽横线、独立数值/状态行和居中首列共同证明两行一组的 rowspan；候选必须完整唯一捕获字符、无歧义且满足原评分条件。Python 与 Rust 均接入既有候选编排，证据不足保留旧路径。
- 0.6.10 `6bdee78`、`014411d`：超限单图保留固定尺寸占位，保留正文、表格、BSE 编号和后续图片。Python 引入文档级去重预算及公式探测缓存，DOC 内联/浮动图共享；Rust 生产图片边界使用可缓存的非致命探测及安全占位，严格底层解码接口和文档结构错误仍传播。普通格式与默认参数不变。
- 0.6.11 `b5502a2`：仅对明确 NUL 的单字节 Type1/TrueType ToUnicode，用该字体 Differences 的 Adobe glyph name 恢复。保留有效映射，支持嵌套 Form、同名字体与共享 CMap。临时 PDF 视图的完整字符序列只允许 NUL 变化，逐字确认字符索引、字框、角度和非生成状态；失败保留原输出。原 PDF 和共享解析缓存不变。Python 使用原 ctypes 路径；Rust 通过 lopdf 创建临时视图，PDFium 句柄始终在同库锁和局部生命周期内。
- 0.6.12 `826f86f`：适配 RapidDoc 自有 lines/spans 段落器。当前页先冻结可信首行缩进证据，只有跨页或向右跨栏才放宽大写首字限制；单行还需同页至少三条同栏后续行证明贴左。保留原标点、宽度、列表分类、数字、引用、竖排及几何保护。不直接引入未使用的上游 raw model-list 段落接口。

## 边界

没有同步 RTF、上游历史语料复查工具、整套 Rust 扩展或修改模型权重。字体异常路径会有临时文档和额外 PDFium 读取开销；正常无 NUL 的页面不解析字体资源、不生成修复视图。Rust 该异常路径先克隆解析对象再裁为目标页，极大的异常文档仍可能产生瞬时内存开销，未声称优化其峰值。

不运行全量评测或 CUDA；本次不证明全局评分或速度提升。构建、安装和受影响回归结果在完成后记录。
