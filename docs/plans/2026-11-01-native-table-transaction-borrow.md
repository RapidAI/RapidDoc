# 原生表格事务与补充候选的页面借用

基于 `native-restore-owned-r2-20261101` 的阶段定位，优化规则表格事务里的页面副本。本轮不修改 Python 生产解析、候选规则、模型、阈值或数值精度。

## 改动

- 表格事务先取出自有来源行，再构造分析页，避免先复制完整行数组、再随整页复制后覆盖；Form/图形处理的行副作用直接更新自有来源数组，不再先复制整组原行。
- 补充候选的 Request 分别借用页面和短期选项。Detector 借用调用方页面，其缓存 Page 直接借用不可变行；不再为了持有缓存而复制整页和原行。局部重新聚类所需的自有 Page 保留。
- 数值候选和矢量公式构建接收来源页与小选项，避免只读调用的整页 JSON 包装。容器阶段直接移交选项、目录块和表格候选/结果。
- 保持原始来源号、保护文字、候选顺序、Form/图形副作用和输出字段；保留数组验证及公开请求的完整树预算验证。有限工作预算仍重新准备，生产无限工作预算仍复用缓存。

这些副本主要来自 Rust 迁移时的 Value 所有权处理。原 Python 表格参考通过 `dataclasses.replace` 和共享文字对象传递数据，不能把本轮收益直接算作 Python 也能获得的收益。

## 针对性验证

- `export_native_table_owned_reference.py` 使用原 Python 表格检测/材质化/代码块函数生成 13 组固定参考：4 份既有真实来源、保护/认领/排除/分隔线及 3 类代码块。另有 3 组矢量公式参考，包括实际构建正例。文件 `tests/fixtures/native_table_owned_reference.json.gz` 保存 Python 来源 SHA。
- 表格参考在生产无限工作预算及 `usize::MAX-1` 有限工作预算（不启用候选缓存）的两类宿主作用域通过；后者用于验证有限预算路径，不代表这些真实页面都能通过旧诊断入口默认一千万工作预算。
- 矢量公式输出/Work、既有 4 份真实完整候选、12 类有限工作预算和直接来源接口对照，以及 6 项已有自有行/分式/图内文字/最终页检查通过，共 10 项受影响 Rust 测试。
- 初次尝试历史候选测试组，4 项通过、22 项因 build/migration 历史语料文件缺失而不能运行；没有为本轮重建整套历史语料。新增表格参考初次使用默认有限诊断预算时触发原有工作量限制，改用上述两类宿主预算验证实际页面，未更改生产资源策略。
- 记录：`build/native-table-borrow-{reference-tests,extra-tests,focused}-20261101.log`。新增参考的生成脚本可独立运行，不依赖已删除的 build/migration 历史 JSON。
