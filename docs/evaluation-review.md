# 共用评测核对页面

项目根目录运行：

```powershell
.venv/Scripts/python.exe demo/review_eval.py
```

会打开 `http://127.0.0.1:8766`。默认读取 `D:/Download/OmniDocBench`：

- “评测目录”切换已评分的 `result_*` 文件夹；显示综合分和预测 Markdown 数量。
- “对比基准”可选择另一组评测，按差值排查退步页面。
- “选择其他评测目录”可选择某次评测目录，或包含多个评测目录的父目录。
- 后续复制新结果后点击“刷新目录”，不需要修改代码或重新生成整套 HTML。

沿用原 PDF/Markdown 并排预览、表格和公式渲染、源码、最差匹配片段与核对记录。
预览按需生成，只处理当前打开的文件；缓存位于数据目录的 `.rapiddoc_review_cache`。
核对记录按评测目录分别保存在浏览器中。共用页面与旧 `file://` 静态报告的浏览器存储相互独立，旧报告和记录保留。

目录对应关系仍为：`result_名称` 保存评分 JSON，旁边的 `名称` 保存预测 Markdown，`pdfs` 保存原 PDF。
缺少 Markdown 时明确报错，避免把空目录当成有效预测。脚本只读取评分结果，不重跑解析或评分。

其他数据根目录可通过 `--root 路径` 指定。仅监听本机回环地址。
原来的 `analyze_eval_errors.py` 仍可用于导出独立静态报告。
